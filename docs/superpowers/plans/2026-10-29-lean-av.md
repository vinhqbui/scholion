# Lean av Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut the tokens av's workflow costs agents (ritual calls, big context results), fix the bench so agents can run tests, then measure lean av against `notes` and `cold` on E4.

**Architecture:** Small changes at the existing seams: the daemon's `submit` handler and MCP text (`crates/scholion-daemon`), the CLI (`crates/scholion-cli`), the shared `coverage` helper (`flow.rs`), and the bench spec/runner (`crates/scholion-bench`). No new crates, no migrations.

**Tech Stack:** Rust 1.97.1 (pinned), axum, clap, sqlx/Postgres (`TestDb`), Claude Code headless for the bench.

**Spec:** `docs/superpowers/specs/2026-10-29-lean-av-design.md`

## Global Constraints

- Agent-facing text (MCP instructions, tool descriptions, hook messages, CLI hints) says `av`, not `scholion`.
- Record summaries ≤ 200 chars; records append-only.
- `submit` stays refused without an intent plus at least one decision/attempt/note/handoff record (inline records count once written).
- Default context budget for `get_context` (MCP) and `av context` (CLI): **800** tokens.
- Bench default: av arms run **without** the MCP server; `--av-mcp` turns it on.
- `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace` green before each commit. Work on branch `e4-harder`.
- Commits by `git -c user.name="VINH BUI" -c user.email="7400756+vinhqbui@users.noreply.github.com" commit`, message ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_011hXky98cVXSWhmwzhsFqWh`.

## Review Focus

1. Inline records where one is invalid (summary > 200 chars, bad kind): the whole submit must fail and write **no** record (no half-applied submit). Test in Task 2.
2. `submit` with inline records on a task that had none: the gate must see them (written before the gate). Test in Task 2.
3. `av submit --record` with a malformed spec (no `:` after the kind): a clear local error, nothing sent. Test in Task 3.
4. `path_prepend` naming a missing directory: `check` warns, the run still works. Test in Task 1.
5. A change touching only test functions: the stop hook stays silent, but a change to real code plus tests still nudges and names only the real symbols. Test in Task 4.
