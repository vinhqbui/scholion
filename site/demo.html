What you just watched, and why it matters.

    

      
The why survives the handoff
Claude's decision and dead end were the first thing Codex received, anchored to pricing.py:line_total and pricing.py:total, and marked "changed since recorded" where the code had moved on.

      
Packs fit, deterministically
No LLM chooses the context. Seeds, a reference graph and a token budget do, so the same state always gives the same pack, and every pack has a receipt.

      
Agents can't trip over each other
One jj workspace per task, claims that fence off stale writers, approvals bound to a tested head, and main that only moves through merge.
